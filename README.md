# J.Jc DFW Lawn Care Services LLC - Website & Landing Page

A modern, high-converting, mobile-responsive landing page created for **J.Jc DFW Lawn Care Services LLC**.

## Features Included
- **Hero & Value Proposition:** Highlighting 5.0-star rating across 39 verified Google reviews.
- **Direct Lead Capture Form:** Easy quote request form with immediate confirmation state.
- **Service Offerings:** Detailed breakdown of lawn mowing, yard transformations, hedge trimming, leaf cleanups, and mulching.
- **Verified Customer Testimonials:** Real client reviews featured directly from Google Maps (Nancy F., Mercy Munuhe, Zman-jones).
- **Embedded Google Map & Address:** Accurate Dallas location (`5834 Plum Dale Rd, Dallas, TX 75241`) and navigation directions.
- **Click-to-Call Buttons:** Integrated throughout the page, including a sticky bottom action bar for mobile visitors.
- **Local SEO & Schema.org:** Built-in `HomeAndConstructionBusiness` structured data for Google local search ranking.
- **Interactive FAQ Accordion:** Quick answers for common prospective client questions.

## How to View
Double-click `index.html` in your file explorer to open it in any web browser, or serve it using any local static server:

```powershell
# Using Python
python -m http.server 8000

# Or using npx serve
npx serve .
```
